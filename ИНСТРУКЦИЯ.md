## 1. Общая картина

```
┌─────────────┐     HTTP      ┌──────────────────┐     SQL      ┌────────────┐
│  Браузер    │ ────────────► │  FastAPI         │ ───────────► │ PostgreSQL │
│ index.html  │ ◄──────────── │  app/main.py     │ ◄─────────── │   docdb    │
└─────────────┘               └──────────────────┘              └────────────┘
                                      │
                                      ▼
                              templates/  exports/
```

**Сценарий работы:**

1. Открыть http://localhost:8000/
2. Загрузить DOCX (рабочая программа или ФОС)
3. Слева — дерево глав и подглав; справа — редактор TinyMCE
4. Сохранить правки в PostgreSQL
5. Экспортировать DOCX по выбранному шаблону

**Стек:**

| Слой | Технологии |
|------|------------|
| API | FastAPI, Uvicorn |
| БД | PostgreSQL, SQLAlchemy async, asyncpg |
| Парсинг | python-docx (по стилям Word), PyMuPDF (PDF) |
| Экспорт | python-docx, html_converter |
| UI | index.html, TinyMCE |

## 3. Запуск проекта

### Требования

- Python **3.12 или 3.13** (рекомендуется; 3.14 может работать нестабильно)
- PostgreSQL с базой **`docdb`**

### Быстрый старт (Windows, cmd)

```cmd
cd D:\Syllabus\myproject
setup.bat
run.bat
```

В PowerShell для `run.bat` используйте `.\run.bat`.

### База данных

Если базы `docdb` нет:

```cmd
psql -U postgres -h 127.0.0.1 -c "CREATE DATABASE docdb;"
```

### Файл `.env`

```env
DATABASE_URL=postgresql+asyncpg://postgres:ПАРОЛЬ@127.0.0.1:5432/docdb
TEMPLATES_DIR=./templates
EXPORTS_DIR=./exports
```

### Проверка БД

```cmd
venv\Scripts\python.exe test_sqlalchemy.py
```

### Запуск вручную

```cmd
venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 5. Как данные проходят через систему

### Загрузка DOCX

1. `POST /api/v1/upload/` — файл в память
2. `DocumentParser` определяет тип (`rp`, `fos`, `generic`)
3. Разделы с `level`, `parent_id`, `order_index` сохраняются в БД
4. Ответ — `DocumentOut` со списком разделов

### Редактирование

1. `PATCH /api/v1/sections/{id}/` — обновление HTML-контента
2. `content_plain` пересчитывается через BeautifulSoup

### Экспорт

1. `GET /api/v1/export/{doc_id}/?template_id=...`
2. Секции собираются в словарь `{имя: html}`
3. Шаблон копируется в `exports/`, плейсхолдеры заменяются

## 6. Парсер: РП и ФОС

Для типовых документов вуза парсер использует **стили Word**, а не любую цифру в тексте.

### Рабочая программа (РП) — `doc_type: rp`

| Стиль Word | Уровень |
|------------|---------|
| `РПд пункты` | 1 — глава |
| `РПд подпункты` | 2 — подглава |
| `Аннотация заголовок` / `Аннотация подзаголовки` | 1 / 2 |
| `РПд текст`, `РПд ср пункты` | содержимое раздела |

### Фонд оценочных средств (ФОС) — `doc_type: fos`

| Стиль Word | Уровень |
|------------|---------|
| `ФОСд заголовки` | 1 — глава |
| `ФОСд позаголовки` | 2 — подглава |
| `ФОСд текс` | содержимое |
| Нумерация `2.1.1.` | 3 — под-подглава |

### Поддерживаемые форматы

- **DOCX** — основной формат
- **PDF** — общий парсер (без стилей Word)
- **DOC** (старый Word) — **не поддерживается**, нужна конвертация в DOCX

Примеры для тестов лежат в `samples/`.

## 7. API

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | UI (index.html) |
| POST | `/api/v1/upload/` | Загрузка PDF/DOCX |
| GET | `/api/v1/documents/{id}/` | Документ с разделами |
| PATCH | `/api/v1/sections/{id}/` | Обновить контент раздела |
| GET | `/api/v1/export/{id}/?template_id=` | Экспорт DOCX |
| GET | `/api/v1/templates/` | Список шаблонов |
| POST | `/api/v1/templates/` | Загрузить шаблон (Swagger/curl) |

Документация Swagger: http://localhost:8000/docs

### Шаблон Word

В шаблоне используются метки вида `{{1.1. Цели и задачи дисциплины}}` — имя должно **точно совпадать** с названием раздела после парсинга.

## 8. Известные ограничения

| Проблема | Статус |
|----------|--------|
| Экспорт HTML из TinyMCE — пустые абзацы на месте плейсхолдеров | Нужно исправить `html_converter.py` |
| Нет загрузки шаблонов через UI | Только API / Swagger |
| Нет каталога документов и копирования на новый год | Не реализовано |
| Нет пакетной загрузки ~2700 файлов | Не реализовано |
| Плейсхолдеры по полному имени раздела — хрупко | План: коды полей `{{RP_GOALS}}` |
| Формат `.doc` | Не поддерживается |
