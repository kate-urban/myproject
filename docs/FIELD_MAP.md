## 1. Форматы учебных планов (plx)

В samples **два разных формата** — это важно для импортёра на шаге 1.

### 1.0 Нативный XML `*.plx` (АС UpVo / MMIS)

Пример: `M540401-2026.plx`, `M540401-2026oz.plx`

| Свойство | Значение |
|----------|----------|
| Формат | UTF-16 XML (`<?xml … encoding="utf-16"?>`) |
| Приложение | UpVo (версия в атрибуте `AppVersion`) |
| Дисциплины | Тег `<ПланыСтроки … ДисциплинаКод="Б1.О.01.07" Дисциплина="…" ТрудоемкостьКредитов="11" ЧасовПоПлану="396" КодКафедры="55"/>` |
| Компетенции | `<ПланыКомпетенции>`, связи `<ПланыКомпетенцииДисциплины>` |
| Метаданные | `<Планы … Титул="…54.04.01 Дизайн…Экодизайн" ГодНачалаПодготовки="2026"/>` |

**Не открывается openpyxl** — нужен XML-парсер (`xml.etree` / `lxml`).

### 1.1 Excel `*_plx.xlsx` (экспорт/отчётный)

| Лист | Приоритет | Назначение | Куда в БД |
|------|-----------|------------|-----------|
| **План** | 🔴 MVP | Дисциплины, часы, з.е., аттестация | `study_plans`, `plan_disciplines` |
| **Компетенции(2)** | 🔴 MVP | Шифр → список компетенций | `plan_discipline_competencies` |
| **Компетенции** | 🟡 | Индикаторы ФГОС ↔ дисциплины | `fgos_indicators`, связи |
| ПланСвод | 🟡 | Свод без колонки СР (ауд. часов) | дубль для сверки |
| Курс 1…N | 🔵 | Часы по семестрам | `plan_discipline_semesters` (позже) |
| Практики, Курсовые, ГЭК | 🔵 | Отдельные блоки | `practices`, `gia_programs` |
| Кафедры | 🔵 | Справочник | `departments` |
| Титул | 🔵 | Направление, профиль, год | метаданные `study_plans` |

**Строка заголовков листа `План`** (строка 3 в plx):

| Колонка | Поле |
|---------|------|
| A | Считать в плане (+/пусто) |
| B | **Индекс** (шифр): `Б1.О.01` |
| C | **Наименование** |
| D–G | Формы аттестации (экзамен, зачёт, зачёт с оц., КП, КР) |
| I–J | з.е. (экспертное / факт) |
| K–L | Итого часов (экспертное / по плану) |
| M | Контактная работа (контроль) |
| N | Аудиторные |
| O | **СР** (самостоятельная работа) |
| P+ | Часы по семестрам (курс 1…) |

**Лист `Компетенции(2)`:** иерархия Б1 → Б1.О → Б1.О.01 → название → колонка «Формируемые компетенции» (`УК-4.3; УК-4.4; …`).

**Очная vs очно-заочная:** пары файлов `*_plx.xlsx` / `*_oz_plx.xlsx` — одно направление, разные формы; в БД поле `form`.

## 2. Форматы Word (РПД / практика / ФОС)

### 2.1 Тип документа

| Префикс / признак | `doc_type` |
|-------------------|------------|
| `FOS_*.docx` | `fos` |
| `B2_*` + «практика» в тексте | `practice` |
| Остальные `B*.docx` | `rpd` |

### 2.2 Стили абзацев (РПД) — уже поддерживаются парсером

| Стиль Word | Уровень | Раздел |
|------------|---------|--------|
| `РПд пункты` | 1 | 1., 2., 3. … |
| `РПд подпункты` | 2 | 1.1., 3.1. … |
| `РПд текст` | — | содержимое |
| `РПд ср пункты` | — | раздел 3.5 СР |
| `РПд таблица` | — | подписи к таблицам |
| `Аннотация заголовок/подзаголовки` | 1/2 | аннотация |

### 2.3 Таблицы Word → сущности БД

Эталон: `B1_O_01_07_Proektnaya_deyatelnost_k55.docx` (24 таблицы)

| type (классификатор) | Пример idx | Сущность / поля |
|----------------------|------------|-----------------|
| `passport_signatures` | T0 | подписи (директор, руководитель ОПОП) |
| `passport_discipline` | T1 | `code`, `name` |
| `passport_direction` | T2 | `direction_code`, `direction_name` |
| `passport_profile` | T3 | `profile_name` |
| `passport_department` | T4 | `department_name` |
| `volume_13` | T9 | лекции, практика, лаб., СР, формы обучения |
| `competencies` | T10–11 | УК / ОПК таблицы раздела 2 |
| `topics_31` | T12 | темы + трудоёмкость + ЗУВ (текст) |
| `sr_35` | T13 | виды СР + часы по формам |
| `topics_31_detailed` | T14–15 | № темы, лек/практ/лаб/СР, компетенции, оцен. средства |
| `literature` | — | раздел 4 (уточнить idx по файлу) |
| `mto` | — | раздел 5 |
| `grading_criteria` | T20–21 | критерии оценки (ВКР/зачёт) |

**ФОС** (`FOS_B1_O_13_...`): стили часто `Normal`, не `ФОСд`. Парсинг — **по заголовкам таблиц**, не по стилям.

### 2.4 Текстовые разделы (HTML в текущей модели)

Для MVP можно оставить `sections` для prose-блоков (1.1 цели, аннотация, методрекомендации), а **табличные данные** — в отдельных таблицах БД.

## 3. Связь имён файлов и шифров

| Шифр в документе | Имя файла |
|------------------|-----------|
| `Б1.О.01.07` | `B1_O_01_07_...` |
| `Б2.О.03(П)` | `B2_O_03_P_...` |
| `Б1.В.02.05` | `B1_V_02_05_...` |
| Сuffix `k55` | кафедра 55 (из справочника / имени) |

**Алгоритм сопоставления (черновик):**

1. Нормализовать шифр: кириллица→латиница, `.` сохранять, скобки `(П)` → `_P`.
2. Искать файл `%B1_O_01_07%` в каталоге.
3. Сверить код из паспорта таблицы T1 в DOCX с записью `plan_disciplines`.
